# git

一个用于学习 Git 版本控制的基础示例仓库。

## 项目简介

本仓库用于演示 Git 的基本提交流程，包含：
- 初始化本地仓库
- 添加与提交文件
- 推送到远程仓库（GitHub）

## 项目结构

git/
├── README.md   # 项目说明文档
└── hello.py    # 示例 Python 脚本

## 使用说明

运行 hello.py：

python hello.py

预期输出：

Hello Git

## Git 基本流程

查看当前状态
git status

将文件加入暂存区
git add hello.py

提交到本地仓库
git commit -m "提交说明"

推送到远程仓库
git push
